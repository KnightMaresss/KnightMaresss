## 📌 Featured Projects

### 🔹 [DiagnoFast](https://github.com/KnightMaresss/DiagnoFast) — Full-Stack AI Medical Diagnosis
A modern web application that uses Natural Language Processing (NLP) to analyze patient symptoms in plain English and predict probable diseases. 
- **Architecture:** React frontend, Node.js backend, and a Python Flask ML microservice.
- **AI:** Custom TF-IDF + LinearSVC pipeline with input validation and confidence scoring.
- **Database:** MongoDB (auto-saves diagnosis history).

### 🔹 [EEG ASD Screening Tool](https://github.com/KnightMaresss/eeg-asd-screening) — Autism Detection from Brain Signals
A desktop application that classifies resting-state EEG recordings as ASD or neurotypical using spectral features and a Random Forest classifier.
- **Accuracy:** 77.6% Mean CV Accuracy.
- **Stack:** Python, PySide6 (GUI), MNE-Python (Signal Processing), scikit-learn.

### 🔹 [CodNexia](https://github.com/KnightMaresss/CodNexia) — Digital Services Marketplace
Full-stack SaaS marketplace with real-time messaging, crypto payments, notifications, and a complete admin panel.
**Live:** [codnexia.com](https://codnexia.com)

### 🔹 [Cliporea Showcase](https://github.com/KnightMaresss/cliporea-showcase) — B2B Marketplace
B2B marketplace for video editors and streamers with automatic TRON blockchain detection, crypto payments, and a full admin dashboard.
**Live:** [cliporea.com](https://www.cliporea.com/en)

### 🔹 [Malware Detection System](https://github.com/KnightMaresss/Malware-Detection) — AI-Powered Threat Scanner
A full-stack malware analysis platform that combines a custom Machine Learning model with VirusTotal's multi-engine analysis.
- **Architecture:** React frontend, Node.js backend, and a Python FastAPI ML microservice.
- **AI:** Custom LightGBM classifier trained on the EMBER 2018 dataset (95.5% accuracy, 0.99 ROC-AUC) with Explainable AI feature extraction.
- **Security:** JWT authentication, strict file validation, and cryptographically signed webhooks between Node and Python.
- **Premium UI:** Sleek dark-mode SaaS interface built with Tailwind CSS and Framer Motion.
